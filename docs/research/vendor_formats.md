SQLite schema additions (not in datasets.md): gop table `(eventId, startTime, endTime, zoneId, offset, len, frame_cnt)`;
event table `(eventId UNIQUE, startTime, endTime, channelId, zoneId, blkId, eventType, mainGopLen, subGopLen, audioGopLen, lockFlag)`;
time-info table `(chnId UNIQUE, avLastWirte, avFirstWrite, picLastWirte, picFirstWrite)` [sic]; tag table `(tagTime, channelId, zoneId, eventId, tagName)`;
log table `(id UNIQUE, mainType, subType, time, detail TEXT)` (-> **system log lives on the HDD in SQLite**); picture table `(fileId, startTime, channelId, zoneId, eventType, imageLen, encodeType, offset, len)`; `tMetadata(name STRING, value BLOB)`; version table `(verId PRIMARY KEY)`.

`research/fw_vigi/rootfs/usr/lib/libstorage.so`: 0x367a6 `Fst section: gop len(head) error(frm %d), frm_calc_len=%u, gop_len=%u` (GOP = header + frames, frame count in header); 0x37e69 `tp_fdisk for %s` + 0x37ed3 `write len: %d/512` (tp_fdisk writes a 512-byte partition sector itself); 0x37fcc `mdadm -As %s &` (RAID = Linux md).
`research/fw_vigi/rootfs/bin/nvrcore` (1,042,328 B): a full **MPEG-TS demuxer** (`MPEGTSDemuxParsePacket` 0x1cfa8, `MPEGTSDemuxGetLastUTCTime` 0x159c9, `MBUFFERESSideInfoSetUTCTime` 0x1c8f6) - VIGI cameras deliver MPEG-TS (TP-Link private HTTP stream) with a **UTC time side-info**; 0xe897d `FRAME_HEAD_S len(%d)` = internal per-frame header struct. Whether zones hold TS packets or FRAME_HEAD_S+ES is NOT resolvable statically -> LOW; test = look for 0x47 every 188 B inside a zone.

**Parser needs (VIGI):** (1) find format tag `TP-Link Corporation Limited, NVR FOR VERSION x.y.z` near disk start (+CRC'd diskInfo); (2) V0: GPT/tp_fdisk -> swap + ext4 -> `/sys.bin`, SQLite DB (+`-walN`, backup `#bk`) and zone files -> use gop table `(zoneId, offset, len, startTime, endTime, frame_cnt)` + event table (channelId) to cut GOPs; (3) V1 raw: DB Area (64/128/256 MB) main+backup+journal, zones at start_addr + id*ZoneSize. Unknown: exact struct offsets of diskInfo, zone size, GOP-header layout/magic, time base (Unix s vs ms; UTC vs local - nvrcore carries "UTC time" side-info -> MED guess UTC). All testable on one VIGI disk or by disassembly (not done - static strings only).

### QVFS MAGIC NUMBERS - static disassembly of Qualvision `Sofia` (ELF ARM32 at file offset 0x200 of `Sofia`; VA = ELF offset + 0x10000; capstone; nothing executed)
- **Disk head (`IDiskExt::CheckHead`, code VA 0x954ee0; string xref 0x954ed4 -> "int IDiskExt::CheckHead()")**:
  `u32[+0x00] == 0x58455651` = ASCII **"QVEX"** (bytes `51 56 45 58`); `u32[+0x04] == 0x00010000` (version 1.0); `u32[+0x08]` and `u32[+0x0C]` must equal two fields of the disk object (disk geometry/ID - likely total sectors/blocks); `+0x10, +0x14, +0x18, +0x1C` = region start/size pairs that must satisfy `start+size(+1) <= disk_total` (i.e. index-table area and data area bounds). Return -EINVAL (0x15) on mismatch. (HIGH for the constants/offsets; MED for field meaning)
- **Frame head (`CheckFrameHead`, code VA 0x989858)**: `(u32[+0] & 0x00FFFFFF) == 0x00010000` -> bytes **`00 00 01 xx`**; type byte `xx = byte[+3]` must satisfy `(xx+0x20)&0xFF <= 0x0B` -> **xx in 0xE0..0xEB**; `u32[+4]` = length, bounded by block size; debug string "codec = %d, type = %d, prefix[3] = %d". (HIGH)
- So a QVFS signature scan = `QVEX` + `00 00 01 00`(LE 0x10000) at a sector start; frames = `00 00 01 E0..EB` + u32 length (MPEG-PES-like stream-id range, but a Qualvision private header). Times = DHTIME (packed local, no zone).
